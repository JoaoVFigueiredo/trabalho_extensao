
# Projeto de Extensão — Git e GitHub

## Sobre o projeto

Este projeto foi desenvolvido como atividade de extensão para praticar o versionamento de código utilizando Git e GitHub.

## Objetivo

Aprender a controlar alterações nos arquivos, registrar commits e publicar o código em um repositório remoto.

## Tecnologias utilizadas

- HTML
- Visual Studio Code
- Git
- GitHub Desktop
- GitHub
- Live Server

## Execução

O arquivo `index.html` pode ser aberto no navegador utilizando a extensão Live Server do Visual Studio Code.
